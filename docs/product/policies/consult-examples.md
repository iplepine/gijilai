# 마음 통역소 고민 예시 정책

## 개요

마음 통역소 진입 시 사용자가 고민을 쉽게 입력할 수 있도록, 선택된 아이의 나이/성별에 맞는 구체적인 예시 문장을 보여준다.

예시는 진단이나 평가 문항이 아니라, 사용자가 자기 상황에 맞게 고쳐 쓸 수 있는 상담 입력 초안이다.

## 데이터 구조

각 예시는 `{ label, text }` 형태다.

- `label`: 칩 버튼에 표시되는 짧은 요약
- `text`: 칩 선택 시 textarea에 채워지는 구체적 고민 문장

## 예시 그룹 구조

### 나이 구간

| 구간 | 나이 | 주요 고민 영역 |
|------|------|---------------|
| 영아기 | 0~2세 | 수면, 식사, 분리불안, 감각 민감성, 안전 행동, 배변 준비 |
| 유아기 | 3~5세 | 등원, 떼쓰기, 감정 조절, 또래 놀이, 배변/식사/수면 루틴 |
| 초등 저학년 | 6~9세 | 학교 적응, 숙제/준비물, 또래 갈등, 규칙, 화면 사용, 불안 신호 |
| 사춘기 초입 | 10~13세 | 독립성, 가족 대화, 친구/SNS, 학습 압박, 수면, 몸 변화, 경계 설정 |

### 나이 판정 로직

`birthDate`로부터 만 나이(년 단위)를 계산하여 구간 결정:

- 0~2세 → `0-2`
- 3~5세 → `3-5`
- 6~9세 → `6-9`
- 10세 이상 → `10-13`

### 성별

- `gender`가 `female`이면 여아, 그 외 모든 값은 남아로 처리한다.
- 성별은 핵심 분류 기준이 아니라 예시 다양화를 위한 보조 축이다.
- 한국어 예시는 각 나이대별 공통 예시 40개에 성별 보조 예시 10개를 더해 성별별 50개가 되도록 구성한다.
- 성별 보조 예시는 실제 보호자가 떠올리기 쉬운 장면을 넓히기 위한 장치이며, 특정 행동을 특정 성별의 고정 특성으로 설명하지 않는다.

### 그룹 분류

| 그룹 | 나이 | 성별 | 한국어 예시 수 |
|------|------|------|---------------|
| A1 | 0~2세 | 남아 | 50개 |
| A2 | 0~2세 | 여아 | 50개 |
| B1 | 3~5세 | 남아 | 50개 |
| B2 | 3~5세 | 여아 | 50개 |
| C1 | 6~9세 | 남아 | 50개 |
| C2 | 6~9세 | 여아 | 50개 |
| D1 | 10~13세 | 남아 | 50개 |
| D2 | 10~13세 | 여아 | 50개 |

한국어 총 노출 풀: 400개. 영어 예시는 기존 80개를 유지한다.

## 표시 규칙

- 한 번에 **5개** 표시한다.
- 해당 아이의 나이/성별 그룹에서 **5개**를 랜덤 선택한다.
- 현재 구현은 `childBirthDate`, `childGender`, `locale`이 바뀔 때 `useEffect`에서 재계산한다.
- 아이 정보가 없는 경우 **3~5세 남아** 그룹에서 선택한다.
- 후속 상담(`sessionContext` 있음)에서는 예시 칩을 보여주지 않는다.

## 예시 문장 작성 가이드

- 부모가 실제로 말할 법한 구어체로 작성한다.
- 진단명이나 낙인 표현을 쓰지 않는다.
- 특정 성별을 문제 행동과 고정적으로 연결하지 않는다.
- `label`은 짧고 스캔 가능해야 하며, 버튼 안에서 과도하게 길어지지 않게 한다.
- `text`는 아이에게 있었던 일, 부모가 난감한 지점, 반복되는 장면 중 하나 이상을 담는다.
- 전문적 판단이 필요한 내용도 "걱정돼요", "어떻게 반응해야 할지 모르겠어요"처럼 상담 입력 문장으로 유지한다.

## 조사 기준

예시 풀은 아래의 발달/양육 자료에서 공통적으로 다루는 고민 축을 바탕으로 구성했다.

- CDC `Essentials for Parenting Toddlers and Preschoolers`: 2~4세 보호자의 흔한 양육 과제와 긍정적 관계/행동 지도 맥락
- AAP HealthyChildren: 영유아 공격 행동, 배변 훈련, 미디어 사용, 8세 검진에서 확인하는 친구/학교/정서 영역
- Child Mind Institute: 수면, 숙제, 화면 전환, 떼쓰기, 형제 싸움, 학교 불안처럼 예측 가능한 순간에 나타나는 행동 문제
- CDC Healthy Youth Parent Resources: 청소년기의 독립성, 온라인 활동, 친구 관계, 부모 모니터링과 명확한 의사소통
