# 결과 리포트 정책

결과 리포트 페이지(`/report`)는 3개 탭으로 구성된다: **아이 기질**, **양육자 분석**, **기질 맞춤 양육**.

---

## 공통 정책

### 용어 표기
- 영문 약어(NS, HA, RD, P)는 사용자에게 노출하지 않음
- 한글 명칭(자극 추구, 위험 회피, 사회적 민감성, 인내력)만 사용

### AI 리포트 생성
- API: `/api/llm/report` (서버 사이드에서 캐시/생성 분기)
- 출력 포맷: JSON
- 리포트 본문에 영문 약어 사용 금지 (프롬프트에 명시)
- 생성된 리포트는 DB에 캐싱, 포맷 불일치 시 자동 재생성 (`refresh: true`)
- 아이 기질 리포트는 `stream: true` 요청 시 같은 API에서 SSE로 모듈 단위 응답을 받을 수 있다. 서버는 캐시가 있으면 즉시 `cached/completed`를 보내고, 새 생성이 필요하면 `intro → dimensions → insight → strengths → parentingTips → scripts` 순서의 `module` 이벤트를 보낸 뒤 전체 리포트를 저장하고 `completed`를 보낸다.
- 각 탭 진입 시 리포트가 없으면 자동 생성 시작
- 생성 대기 상태에서는 다음으로 작성 중인 섹션 로딩 카드 하나를 노출하고, 섹션명, 작업 문구, 퍼센트 진행률, determinate progress bar를 함께 표시한다.
- 로딩 카드는 반투명 블러 배경으로 표시하되 반복 깜빡임을 만들지 않는다.
- 아이 기질 리포트는 섹션 데이터가 스트리밍으로 도착하는 대로 완료된 섹션을 짧은 fade/slide 애니메이션으로 누적 표시한다. 양육자 분석과 기질 맞춤 양육 리포트는 완성본 수신 후 섹션을 같은 reveal 규칙으로 순차 노출한다.
- 아이 기질 리포트 스트리밍 중에는 다음으로 생성 중인 섹션 로딩 카드 하나를 노출하고, 퍼센트 진행률과 determinate progress bar를 함께 표시한다. 문구는 `아이나의 한마디`, `기질 점수`, `기질 요소별 해석`, `숨겨진 속마음`, `강점`, `양육 가이드`, `마법의 한마디`, `리포트 마무리` 순서로 해당 섹션 작업을 설명한다.
- 한국어 리포트에서 아이 이름 뒤 조사는 입력된 이름 형태에 맞춘다. 성을 제외한 받침 있는 이름은 친근형 이름 규칙을 적용해 `재윤은`이 아니라 `재윤이는`, `재윤을`이 아니라 `재윤이를`로 쓴다. 성까지 포함된 3글자 이상 한글 이름은 일반 조사 규칙을 적용해 `박재윤은`, `박재윤이`, `박재윤을`, `박재윤의`로 쓴다.

### 공유

- 각 탭의 공유 버튼은 현재 탭에 대응하는 최신 리포트 ID를 `/share?id={reportId}`로 전달한다.
- 아이 기질 탭은 `CHILD`, 양육자 분석 탭은 `PARENT`, 기질 맞춤 양육 탭은 `HARMONY` 리포트를 공유한다.
- `/share`의 카카오톡/링크/다른 앱 공유 문구와 `/shared/[id]` 공개 화면은 리포트 타입별 제목, 이미지, 요약 문구를 사용한다.

### 접근 권한
- 현재 모든 섹션은 무료 공개 (유/무료 구분 없음)

### 탭 전환
- 양육자 분석 탭: 양육자 기질 검사(ATQ) 미완료 시 설문 안내 confirm 표시
- 기질 맞춤 양육 탭: 양육 태도 검사(STYLE) 미완료 시 설문 안내 confirm 표시
- `child_only` 모드: URL 파라미터로 아이 기질 탭만 표시하는 quick-start 모드다. 양육자 기질 데이터가 아직 없을 때만 유지하고, 탭 스위처를 숨긴 뒤 하단 CTA로 양육자 검사 이어가기 또는 공유를 안내한다. 양육자 기질 데이터가 이미 있으면 `/report?tab=child` 전체 리포트 모드로 정규화하고 별도 "전체 리포트 보기" CTA는 노출하지 않는다.

### 다시 분석하기
- 각 탭 하단에 분석 날짜와 "다시 분석하기" 버튼 표시
- 클릭 시 즉시 재생성하지 않고 확인 다이얼로그를 먼저 표시한다.
- 다이얼로그 문구는 `기질 분석을 다시 할까요? / 기존 설문 응답은 초기화되고, 처음부터 다시 설문을 진행해요.`를 기본으로 한다.
- 사용자가 확인하면 로컬 설문 응답 저장소(`temperament-storage`, `survey-storage`)와 설문 진행 상태를 초기화한다.
- 아이 기질 탭의 다시 분석은 아이 기질 설문 응답만, 양육자 분석 탭의 다시 분석은 양육자 기질 설문 응답만 초기화한다. 한쪽을 다시 분석해도 다른 쪽 설문과 리포트는 그대로 유지한다.
- 로그인 사용자는 Supabase `surveys`에 해당 설문 타입만 빈 `IN_PROGRESS` 새 시도로 생성해 글로벌 복원 로직이 이전 완료 응답을 다시 불러오지 않게 한다. 기존 완료 설문/리포트 행은 즉시 삭제하지 않는다.
- 기존 분석 결과는 새 설문을 시작하는 순간 즉시 지우지 않는다. 사용자가 새 설문을 중단해도 마지막 안정 리포트는 유지하고, 새 설문 완료 후 `/report`가 `refresh` 모드로 새 응답 기준 리포트를 생성하면 기존 캐시를 교체한다.
- 아이 기질 또는 양육자 기질 중 하나를 새로 분석하면 기존 기질 맞춤 양육 리포트는 이전 조합 기준일 수 있으므로, 리포트 화면에서 하모니 재분석 CTA를 안내한다. 하모니 재분석은 설문을 초기화하지 않고 기존 최신 응답으로 `HARMONY` 리포트만 `refresh` 생성한다.
- `child_only` 리포트의 다시 분석은 `/survey?flow=quick` 첫 문항으로 돌아가되, 완료 후 양육자 기질 데이터가 있으면 전체 리포트 아이 탭으로 정규화한다. 전체 리포트에서 아이 기질 다시 분석은 아이 설문만 완료한 뒤 전체 리포트 아이 탭으로 돌아온다. 양육자 분석 다시 분석은 양육자 기질 설문만 완료한 뒤 양육자 탭으로 돌아온다.

### 의료 관련 안내
- 리포트 결과 하단 CTA 영역에는 의료 관련 면책 안내를 노출한다.
- 문구는 기질 이해를 돕기 위한 참고 자료이며 의학적·심리학적 진단을 대체하지 않는다는 점을 명시한다.
- 건강이나 발달 관련 우려가 있으면 전문기관에 상담하도록 안내한다.

## 1. 아이 기질 탭

| 순서 | 섹션 | 데이터 키 | 목적 |
|------|------|-----------|------|
| 0 | 히어로 영역 | `childType` | 기질 유형명, 키워드 태그, 한 줄 설명. 미완료 시 스켈레톤 |
| 1 | 아이나의 한마디 | `intro` | 아이 기질 유형의 핵심 특성 해설 |
| 2 | 기질 점수 카드 | `childScores` | 4대 기질 점수(0~100) 프로그레스 바 시각화 (2x2 그리드) |
| 3 | 기질 요소별 해석 | `analysis.dimensions` | 각 차원별 점수 기반 상세 해석 |
| 4 | 아이의 숨겨진 속마음 | `analysis.insight` | 오해하기 쉬운 행동 뒤의 진짜 마음 (배열 또는 문자열) |
| 5 | 강점과 성장 가능성 | `analysis.strengths` | 아이의 기질적 강점과 성장 방향 |
| 6 | 양육 가이드 | `parentingTips[]` | 상황별 구체적 양육 팁 (situation + tips 배열) |
| 7 | 마법의 한마디 | `scripts[]` | 실전 대사 (situation + script + guide) |

### 세부 규칙

- **기질 점수 카드**: 점수 0~100, 프로그레스 바 시각화. 4차원 각각 색상 구분
- **기질 요소별 해석**: `dimensions` 필드가 없거나 모든 값이 falsy면 미표시
- **아이의 숨겨진 속마음**: 배열(`scene` + `content`)이면 카드별 표시, 문자열이면 단일 블록
- **양육 가이드**: 상황 제목(`situation`) + 팁 목록(`tips[]`)
- **마법의 한마디**: `script` 필드의 양끝 따옴표 자동 제거 처리
- **스트리밍 표시**: 아이 기질 리포트는 `intro`, `dimensions`, `insight`, `strengths`, `parentingTips`, `scripts` 모듈이 도착하는 순서대로 화면에 누적 표시한다. 분석 날짜, 공유, 하단 CTA는 서버 저장이 완료된 `completed` 이후에만 노출한다.
- **섹션별 로딩**: 스트리밍 중 아직 모듈이 도착하지 않은 영역을 한꺼번에 펼치지 않는다. 완료된 섹션은 짧은 fade/slide 애니메이션으로 누적 표시하고, 다음 생성 섹션 카드 하나만 해당 섹션명, 작업 문구, 퍼센트 기반 determinate progress bar와 함께 표시한다. 로딩 카드는 반투명 블러 배경으로 표시하되 반복 깜빡임은 만들지 않는다. 마지막 저장 대기 구간에는 `마지막으로 리포트를 저장하고 공유 준비를 하고 있습니다...`를 표시한다.

## 2. 양육자 분석 탭

| 순서 | 섹션 | 데이터 키 | 목적 |
|------|------|-----------|------|
| 0 | 히어로 영역 | `parentType` | 양육자 기질 유형명, 키워드, 한 줄 설명. 미완료 시 스켈레톤 |
| 1 | 아이나의 한마디 | `intro` | 양육자 기질의 핵심 특성 해설 |
| 2 | 기질 점수 카드 | `parentScores` | 양육자 4대 기질 점수 프로그레스 바 시각화 |
| 3 | 기질 요소별 해석 | `dimensions` | 각 차원별 상세 해석 |
| 4 | 내가 가장 빛나는 순간 | `shining` (또는 `sections[id=shining]`) | 에너지 넘치는 상태, 가장 빛나는 순간 |
| 5 | 나의 양육 기질 | `parentingStyle[]` | 양육 장면별 기질 분석 (scene + content 카드) |
| 6 | 에너지 고갈 신호 | `vulnerability` (또는 `sections[id=vulnerability]`) | 취약 상황과 고갈 신호 |
| 7 | 나를 위한 마음 영양제 | `solutions[]` | 퍼스널 솔루션 (name + action + reason) |
| 8 | 아이나의 편지 | `letter` | 문학적이고 다정한 2인칭 톤 편지 |

### 세부 규칙

- **기질 요소별 해석**: `dimensions` 필드가 있을 때만 표시
- **shining / vulnerability**: 레거시 호환을 위해 `sections` 배열 fallback 지원
- **마음 영양제**: name(이름) + action(행동 지침) + reason(기질적 근거) 3개
- **아이나의 편지**: `From. 아이나` 라벨, 로즈 색상 배경, 이탤릭체
- **섹션별 로딩**: 생성 중에는 `아이나의 한마디`, `양육자의 기질 점수`, `기질 요소별 해석`, `내가 가장 빛나는 순간`, `나의 양육 기질`, `에너지 고갈 신호`, `나를 위한 마음 영양제`, `아이나의 편지`, `리포트 마무리` 순서로 섹션 로딩 카드를 표시한다.

## 3. 기질 맞춤 양육 탭

| 순서 | 섹션 | 데이터 키 | 목적 |
|------|------|-----------|------|
| 0 | 히어로 영역 | `harmonyTitle` + `oneLiner` | AI 생성 관계 이름 + 한 줄 정의. 로딩 중 스켈레톤 |
| 1 | 기질 비교 레이더 차트 | `childScores` + `parentScores` | 4대 기질 점수 시각 비교 (아이=파랑, 양육자=주황) |
| 2 | 관계 카드 | `harmonyTitle` + `compatibilityScore` + `oneLiner` | 관계 이름 + 궁합 점수(%) + 한 줄 정의 |
| 3 | 핵심 기질 차이 | `coreGap` | 가장 큰 점수 차이 차원 + 관점 전환(reframe) |
| 3-2 | 마음이 잘 맞는 부분 | `coreMatch` | 점수 차이가 작은 차원의 공통점 + 강점. 없으면 미표시 |
| 4 | 양육 원칙 | `parentingPrinciples[]` | title + why + DO/DON'T |
| 5 | 이럴 때 이렇게 | `situationalTips[]` | 상황별 대처법 + 실전 대사 |
| 6 | 양육 스타일 점검 | `parentingAudit` | currentStyle + evaluation + adjustment(조절 포인트) |
| 7 | 오늘의 한 마디 | `dailyReminder` | 냉장고에 붙여둘 핵심 메시지 |

### 세부 규칙

- **레이더 차트**: 로딩 중 800ms 간격 랜덤 값 애니메이션, 완료 후 실제 점수로 전환
- **레거시 호환**: `dynamics` 필드가 있는 구 포맷 감지 시 "새로운 양육 가이드로 업그레이드" 버튼 표시
- **양육 원칙**: DO/DON'T 포함, 범용적 육아 조언 금지
- **이럴 때 이렇게**: situation + childFeeling(아이의 속마음) + parentTrap(빠지기 쉬운 반응) + betterResponse(권장 반응) + script(실전 대사)
- **실전 대사**: 양끝 따옴표 자동 제거 처리
- **오늘의 한 마디**: 30자 이내, "냉장고에 붙여두세요" 안내 표시
- **섹션별 로딩**: 생성 중에는 `기질 비교`, `관계 카드`, `핵심 기질 차이`, `마음이 잘 맞는 부분`, `양육 원칙`, `이럴 때 이렇게`, `양육 스타일 점검`, `오늘의 한 마디`, `리포트 마무리` 순서로 섹션 로딩 카드를 표시한다.

## 구독 유도

- 비구독자가 리포트를 확인한 뒤 하단에 프리미엄 CTA를 노출한다.
- CTA는 "리포트에서 끝내지 않고 이 아이의 상담/실천 기록을 계속 쌓아 다음 상담에 반영한다"는 가치 중심으로 작성하고 `/pricing`으로 이동한다.
- 공유/홈 이동 버튼보다 먼저 배치해 리포트 확인 직후의 전환 경로를 명확히 한다.
