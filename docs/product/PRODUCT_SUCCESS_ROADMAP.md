# 기질아이 제품 성공 로드맵

Status: Active
Date: 2026-05-10

## 1. 배경과 목표

이 문서는 기질아이의 성공 가능성을 높이기 위한 제품 실행 로드맵을 정리한다.
기준 문서는 [USE_CASES.md](USE_CASES.md)이며, 현재 사용자 여정 위에서 무엇을 먼저 검증하고 어떤 순서로 개선할지 합의하는 것이 목적이다.

핵심 질문은 세 가지다.

- 무료 리포트가 신뢰를 만들고 다음 행동으로 이어지는가
- AI 상담이 실제 재방문과 실천을 만드는가
- 실천/기록 루프가 구독 전환과 유지로 이어지는가

## 2. 현재 상태 요약

### 강점

- 타깃이 `3~7세 자녀를 둔 양육자`로 비교적 선명하다.
- `랜딩/로그인 → 아이 등록 → 설문 → 리포트 → 상담 → 실천 → 회고` 흐름이 구조적으로 이어져 있다.
- 리포트 공유, 가족 열람, 추천 코드 유입 등 약한 바이럴 루프가 이미 설계되어 있다.
- 상담과 기록이 누적될수록 가치가 커지는 형태라 리텐션형 제품이 될 여지가 있다.
- 홈에서 정상 진행 실천은 즉시 체크할 수 있고, 마무리할 실천은 실천 탭으로 연결해 루프를 끊지 않게 했다.
- 다자녀 맥락은 실천 카드 아이 태그와 상담 인사 아이 이름 강조로 보강했다.

### 리스크

- 무료 리포트가 강한 흡인점이지만, 상담/구독 전환으로 이어지지 않으면 일회성 사용으로 끝날 수 있다.
- 육아 도메인은 신뢰 장벽이 높아서 상담 품질이 체감 효용을 만들지 못하면 재방문이 어렵다.
- 실천/관찰 기록은 가치가 있어도 입력 부담이 크면 루프가 쉽게 끊긴다. 회고 선택 입력과 홈 즉시 체크를 유지하되, 실제 완료율을 확인해야 한다.
- 경쟁 대체재가 넓다. 부모 커뮤니티, 육아 콘텐츠, 범용 LLM 대비 차별이 약하면 방어력이 낮다.

### 2026-05-10 업데이트

- 홈 스크롤 reveal 애니메이션을 제거해 짧은 홈 콘텐츠가 바로 보이게 했다.
- 홈 대표 실천 카드에서 미리보기 2개 외 남은 항목을 `+N개 더`로 표시한다.
- `실천 정리하기` 계열 용어를 `실천 마무리하기`로 정리했다.
- 실천 마무리 회고는 선택 입력으로 바꿨고, 빈 회고는 다음 상담 LLM 컨텍스트에 주입하지 않는다.
- 현재 작업 관리는 `docs/work/TODO.md`와 `R-002-practice-loop-retention`에서 추적한다.

## 3. 핵심 성공 가설

### H1. 무료 리포트가 다음 행동을 만든다

- 사용자는 리포트를 본 뒤 `이 서비스는 믿을 만하다`고 느끼고 상담 또는 전체 분석으로 이동한다.
- 실패 신호: 리포트 열람은 높지만 상담 클릭, 체험 진입, 공유 전환이 낮다.

### H2. AI 상담이 실제 도움으로 인식된다

- 사용자는 상담 결과를 읽고 끝내지 않고, 실천 항목을 선택하거나 후속 상담으로 돌아온다.
- 실패 신호: 상담 만족도는 높지만 실천 등록률과 48시간 재방문율이 낮다.

### H3. 실천/기록 입력이 충분히 가볍다

- 사용자는 기록을 별도 숙제로 느끼지 않고, 짧은 메모 수준으로도 루프를 유지한다.
- 실패 신호: 첫 기록 완료율이 낮고 입력 시작 단계에서 이탈한다.

### H4. 상담-실천-회고 루프가 반복 사용을 만든다

- 사용자는 하나의 상담 세션이 끝난 뒤에도 다음 관찰과 후속 질문으로 자연스럽게 이어진다.
- 실패 신호: 상담 세션은 누적되지만 재상담률과 세션 회고 완료율이 낮다.

### H5. 가족 공유가 신규 유입과 재확신을 돕는다

- 리포트 공유는 단순 열람이 아니라 가족 합의와 신규 가입/설문 전환으로 이어진다.
- 실패 신호: 공유 열람은 있으나 로그인/설문 전환이 거의 없다.

## 4. 우선순위 전략

우선순위는 `신뢰 → 반복 사용 → 전환 → 확산` 순서로 둔다.

1. 신뢰
   리포트와 상담이 모두 "그럴듯함"을 넘어서야 이후 단계가 의미 있다.
2. 반복 사용
   실천/기록 루프가 살지 않으면 구독 제품이 아니라 일회성 콘텐츠 제품이 된다.
3. 전환
   무료 리포트와 체험/구독의 경계를 사용자가 납득할 수 있어야 한다.
4. 확산
   가족 공유와 추천은 앞선 세 단계가 안정된 뒤에 효율이 커진다.

| 우선 과제 | 목적 | 연결 유즈케이스 | 확인 지표 |
|-----------|------|------------------|-----------|
| 리포트 신뢰 강화 | 무료 리포트만으로도 서비스 가치와 차별성을 납득시킨다. | UC-06, UC-17 | `report_viewed → consult_started`, `report_viewed → survey_module_started(parent)` |
| 상담 진입 전 불안 해소 | 상담이 우리 아이 상황에 맞는지, 어떤 결과를 주는지 명확히 보여준다. | UC-08, UC-18 | `pricing → consult_started`, `consult_started` 대비 이탈률 |

### 단기 범위 메모

- 리포트와 상담의 설명 카피, 예시, 신뢰 근거, CTA 구조를 먼저 다듬는다.
- 새로운 기능 추가보다 기존 퍼널 해석력과 다음 행동 연결을 우선한다.

## 6. 중기 실행 로드맵 `1~3개월`

| 우선 과제 | 목적 | 연결 유즈케이스 | 확인 지표 |
|-----------|------|------------------|-----------|
| 1-tap 실천/관찰 기록 | 기록 부담을 줄여 루프 이탈을 낮춘다. | UC-09, UC-11, UC-20 | 첫 기록 완료율, 기록 작성 시작 시간 |
| 후속 상담 루프 강화 | 실천 후 변화가 생기면 다시 상담으로 돌아오게 만든다. | UC-10, UC-19 | 재상담률, 세션당 상담 회차 수 |
| 개인화 맥락 누적 | 아이별 이력, 실천, 관찰이 다음 처방에 반영된다는 느낌을 강화한다. | UC-08, UC-10, UC-11, UC-19 | `consult_started(is_followup=true)`, 재방문율 |

### 중기 범위 메모

- `실천 → 기록 → 재상담` 연결성을 강화하는 데 집중한다.
- 사용자의 입력 비용을 줄이되, 다음 상담 품질이 좋아진다는 보상이 눈에 보여야 한다.

## 7. 장기 실행 로드맵 `3~6개월`

| 우선 과제 | 목적 | 연결 유즈케이스 | 확인 지표 |
|-----------|------|------------------|-----------|
| 가족 공유 전환 강화 | 공유 열람을 가입/설문 또는 가족 합의로 연결한다. | UC-12, UC-21 | `shared/[id] → login`, `shared/[id] → survey/intro` |
| 빠른 아이 리포트 경로 최적화 | 첫 효용 경험까지의 거리를 줄여 신규 유입 이탈을 줄인다. | UC-05, UC-06, UC-22 | `survey_intro → report_viewed(child_only=true)` |
| 체험 만료 전후 전환 설계 | 체험 시작, 종료 임박, 만료 후 복귀까지 하나의 라이프사이클로 관리한다. | UC-07, UC-13, UC-22 | 체험 사용자 구독 전환율, 만료 후 14일 복귀율 |

### 장기 범위 메모

- 공유는 유입 채널이기도 하지만, 기존 사용자가 서비스 가치를 다시 확인하는 장치이기도 하다.
- 빠른 아이 리포트와 체험 전환은 서로 분리하지 말고 하나의 초기 퍼널로 봐야 한다.
