# 표준 유즈케이스 요약

상세 유즈케이스 원문은 `../archive/USE_CASES_LEGACY.md`를 보존한다. 이 문서는 현재 제품 판단에 필요한 핵심 흐름만 요약한다.

## UC-01. 시작과 로그인

- 사용자: 신규/기존 양육자
- 목표: 서비스 가치를 이해하고 개인 세션을 만든다.
- 결과: 아이 등록, 설문, 리포트, 상담 데이터가 사용자 계정에 연결된다.

## UC-02. 아이 등록과 접수

- 사용자: 로그인 사용자
- 목표: 분석 기준이 되는 아이 프로필과 고민 맥락을 만든다.
- 결과: 아이별 설문, 리포트, 상담, 실천 이력이 분리된다.

## UC-03. 설문 완료

- 사용자: 리포트를 받으려는 양육자
- 목표: 아이 기질, 양육자 기질, 양육 태도 데이터를 수집한다.
- 결과: `child_only` 리포트 또는 전체 리포트 생성 재료가 준비된다.

## UC-04. 리포트 확인

- 사용자: 설문 완료 사용자
- 목표: 아이/양육자/관계 기질을 이해한다.
- 결과: 리포트 후 전체 분석 확장, 상담 시작, 구독 전환, 공유 중 다음 행동을 선택한다.

## UC-05. AI 상담

- 사용자: 현재 육아 고민이 있는 양육자
- 목표: 고민을 구조화하고, 양육자가 바라는 목표 행동을 분리한 뒤 아이 속마음, 관계 해석, 오늘의 한마디, 실천 처방을 받는다.
- 결과: 상담 세션과 실천 항목이 생성된다.

### UC-05a. 상담 입력 품질 검증
- Goal: 상담 가능한 고민 맥락이 있을 때만 AI 문진을 시작해 무의미한 상담 생성과 비용 낭비를 막는다.
- Actor: 상담을 시작하려는 양육자
- Preconditions: 사용자가 상담 입력 화면에 있고, 상담 접근 권한과 아이 리포트 조건을 충족한다.
- Trigger: 사용자가 `상담 시작하기` 버튼을 누른다.

Basic Flow:
1. 사용자가 아이에게 있었던 일, 부모의 반응, 힘들었던 지점 중 하나 이상이 드러나는 자유 텍스트를 입력한다.
2. 시스템은 입력 길이와 명백한 무의미 패턴을 먼저 검사한다.
3. 입력이 상담 가능한 맥락이면 초기 문진 생성 API를 호출한다.
4. 문진은 표면 문제와 구분해 양육자가 가장 바라는 변화 또는 문제가 나아졌다고 느끼는 모습을 묻는다.

Alternate Flow:
- 입력이 비어 있거나 너무 짧으면 입력창 아래에서 한 문장 더 적도록 안내한다.
- 자모/기호/반복 문자열처럼 의미를 파악하기 어려운 입력이면 상담을 시작하지 않고 구체적인 상황 예시를 보여준다.
- API 직접 호출에서도 같은 검증을 통과하지 못하면 초기 문진을 생성하지 않는다.

Postconditions:
- 유효한 입력과 부모 목표 답변만 상담 문진과 이후 처방 생성에 사용된다.
- 차단된 입력은 저장되지 않고, 사용자는 같은 화면에서 수정할 수 있다.

Implementation Status:
- 현재 구현. 빈 입력, 너무 짧은 입력, 자모/기호/반복 문자열처럼 명백히 의미를 파악하기 어려운 입력은 클라이언트와 초기 문진 API에서 차단한다. 상담 시작 CTA는 로딩 중이 아닐 때 클릭 가능하게 두고, 검증 실패 사유를 입력창 아래에서 안내한다. 상담과 무관하지만 문장 형태는 정상인 입력의 LLM 분류는 아직 미구현이다.

What the user must understand:
- 상담을 막는 이유는 평가가 아니라 아이 상황을 이해할 최소 맥락이 부족하기 때문이다.

What the system must explain:
- 무엇을 더 적어야 하는지, 어떤 예시처럼 쓰면 되는지 입력창 가까이에서 설명한다.

Where to reduce choice fatigue:
- 여러 수정 옵션을 주지 않고, 한 문장 예시 하나만 보여준다.

Defaults / recommendations to show:
- 기본 추천 문구는 `아이에게 있었던 일 + 내가 한 반응 + 가장 힘든 점` 중 하나 이상을 포함한 짧은 예시로 둔다.

### UC-05b. 상담 고민 예시로 시작하기
- Goal: 첫 상담 입력이 막힌 사용자가 비슷한 고민 하나를 골라 상담 가능한 초안을 빠르게 만든다.
- Actor: 상담을 처음 시작하는 양육자
- Preconditions: 사용자가 새 상담 입력 화면에 있고, 아이 정보와 기질 리포트 조건을 충족한다.
- Trigger: 사용자가 `비슷한 고민` 예시 칩을 누른다.

Basic Flow:
1. 시스템은 아이 나이와 성별에 맞는 고민 예시를 여러 개 보여준다.
2. 사용자는 현재 상황과 가장 가까운 예시 하나를 선택한다.
3. 시스템은 선택한 예시 문장으로 고민 입력창을 교체하고, 선택된 칩을 시각적으로 표시한다.
4. 사용자는 예시를 그대로 쓰거나 자기 상황에 맞게 수정한 뒤 상담을 시작한다.

Alternate Flow:
- 다른 예시를 누르면 기존 예시 또는 입력 내용이 새 예시 문장으로 교체된다.
- 사용자가 직접 입력을 수정해 예시 문장과 달라지면 예시 칩은 선택 상태로 보이지 않는다.
- 입력 내용을 다시 시작하고 싶으면 `전체 삭제`로 입력창을 비운다.

Postconditions:
- 상담 시작 전 입력창에는 한 번에 하나의 고민 초안만 남는다.
- 여러 예시가 무의미하게 누적되지 않는다.

Implementation Status:
- 현재 구현. 새 상담 첫 입력 화면에서 예시 칩은 단일 선택/교체로 동작하고, 입력창 하단에 전체 삭제 액션을 제공한다.

What the user must understand:
- 예시는 여러 개를 조합하는 체크리스트가 아니라, 하나를 골라 자기 상황에 맞게 고치는 시작점이다.

What the system must explain:
- 예시 목록 위에서 하나를 골라 초안으로 시작한다는 점을 짧게 설명한다.

Where to reduce choice fatigue:
- 예시는 현재처럼 제한된 개수만 보여주고, 선택은 한 번에 하나만 허용한다.

Defaults / recommendations to show:
- 나이/성별 기반 추천 예시 5개를 보여주며, 선택 후에는 사용자가 직접 수정할 수 있게 자유 입력을 유지한다.

## UC-06. 실천과 기록

- Goal: 상담 처방을 일상 행동으로 옮기고, 멈춤이나 마감까지 다음 상담 맥락으로 남긴다.
- Actor: 상담 처방을 받은 양육자
- Preconditions: ACTIVE 실천 항목이 있고, 각 항목에는 생성일과 권장 기간(`duration`)이 있다.
- Trigger: 사용자가 홈 또는 실천 탭에 들어오거나, 오늘의 실천 기록 버튼을 누른다.
- Basic Flow: 시스템은 정상 진행 중인 실천 중 오늘 미기록 항목을 먼저 추천한다. 사용자는 실천 여부와 짧은 메모 또는 아이 반응을 기록한다. 기록은 다음 상담 컨텍스트에 누적된다.
- Alternate Flow: 마지막 행동 후 3일 이상 기록이 없으면 "다시 이어가기"와 "다른 방법 찾기"를 제안한다. 권장 기간이 지나면 "마감 회고", "3일 더 해보기", "다른 방법 찾기" 중 다음 행동을 제안한다. 권장 기간이 지나고 마지막 행동도 3일 이상 없으면 반복 리마인더 대신 "실천 마무리하기"를 제안한다. 회고 내용은 선택 입력으로 두며, 비워도 저장 후 "이 고민 마무리하기", "다음 상담에 반영하기", "새 고민으로 상담하기" 중 하나를 고르게 한다.
- Postconditions: 오늘 로그, 실천 회고, 연장된 기간, 또는 DROPPED/COMPLETED 상태가 저장되어 다음 상담에 반영된다. 사용자가 고민 마무리를 선택한 경우에만 연결 상담 세션이 `RESOLVED`가 된다.
- Implementation Status: 구현됨. DB 상태값은 `ACTIVE | COMPLETED | DROPPED`를 유지하고, 멈춤/마감 상태는 화면에서 파생 계산한다.
- What the user must understand: 실천을 며칠 쉬었다고 실패가 아니며, 기록은 평가가 아니라 다음 방법을 더 현실적으로 만들기 위한 재료다.
- What the system must explain: 왜 지금 다시 기록, 마감 회고, 연장, 방법 변경 중 하나를 권하는지 마지막 행동일과 권장 기간 기준으로 짧게 설명한다.
- Where to reduce choice fatigue: 홈과 실천 탭은 여러 실천을 같은 강도로 보여주지 않고, 지금 처리할 1개를 먼저 올린다.
- Defaults / recommendations to show: 정상 진행은 오늘 미기록 항목을 추천한다. 3일 이상 멈춤은 재기록을 기본 CTA로 둔다. 기간 완료는 마감 회고를 기본 CTA로 둔다. 오래 멈춘 기간 완료 항목은 실천 마무리를 기본 CTA로 둔다. 회고 후 긍정적 완료 흐름은 고민 마무리를 먼저 두고, 멈춤/조정 흐름은 다음 상담에 반영하기를 먼저 둔다.

## UC-07. 구독과 유지

- 사용자: 체험 종료 또는 반복 상담 니즈가 있는 사용자
- 목표: 상담-실천-기록-후속 상담 루프를 계속 사용한다.
- 결과: 월 구독으로 전환하거나 구독을 유지한다.

## UC-08. 공유와 재유입

- 사용자: 리포트를 가족과 나누려는 사용자
- 목표: 리포트 공유를 통해 가족 합의와 신규 유입을 만든다.
- 결과: 공유 열람자가 로그인, 설문, 리포트 흐름으로 유입될 수 있다.
