# 표준 유즈케이스 요약

상세 유즈케이스 원문은 `../archive/USE_CASES_LEGACY.md`를 보존한다. 이 문서는 현재 제품 판단에 필요한 핵심 흐름만 요약한다.

## UC-01. 시작과 로그인

- 사용자: 신규/기존 양육자
- 목표: 서비스 가치를 이해하고 개인 세션을 만든다.
- 결과: 아이 등록, 설문, 리포트, 상담 데이터가 사용자 계정에 연결된다.

## UC-02. 아이 등록과 접수

- 사용자: 로그인 사용자
- 목표: 분석 기준이 되는 아이 프로필과 고민 맥락을 만든다.
- 결과: 아이별 설문, 리포트, 상담, 실천 이력이 분리된다.

## UC-03. 설문 완료

- 사용자: 리포트를 받으려는 양육자
- 목표: 아이 기질, 양육자 기질, 양육 태도 데이터를 수집한다.
- 결과: `child_only` 리포트 또는 전체 리포트 생성 재료가 준비된다.

## UC-04. 리포트 확인

- 사용자: 설문 완료 사용자
- 목표: 아이/양육자/관계 기질을 이해한다.
- 결과: 리포트 후 전체 분석 확장, 상담 시작, 구독 전환, 공유 중 다음 행동을 선택한다.

## UC-05. AI 상담

- 사용자: 현재 육아 고민이 있는 양육자
- 목표: 고민을 구조화하고 아이 속마음, 관계 해석, 오늘의 한마디, 실천 처방을 받는다.
- 결과: 상담 세션과 실천 항목이 생성된다.

## UC-06. 실천과 기록

- Goal: 상담 처방을 일상 행동으로 옮기고, 멈춤이나 마감까지 다음 상담 맥락으로 남긴다.
- Actor: 상담 처방을 받은 양육자
- Preconditions: ACTIVE 실천 항목이 있고, 각 항목에는 생성일과 권장 기간(`duration`)이 있다.
- Trigger: 사용자가 홈 또는 실천 탭에 들어오거나, 오늘의 실천 기록 버튼을 누른다.
- Basic Flow: 시스템은 정상 진행 중인 실천 중 오늘 미기록 항목을 먼저 추천한다. 사용자는 실천 여부와 짧은 메모 또는 아이 반응을 기록한다. 기록은 다음 상담 컨텍스트에 누적된다.
- Alternate Flow: 마지막 행동 후 3일 이상 기록이 없으면 "다시 이어가기"와 "다른 방법 찾기"를 제안한다. 권장 기간이 지나면 "마감 회고", "3일 더 해보기", "다른 방법 찾기" 중 다음 행동을 제안한다. 권장 기간이 지나고 마지막 행동도 3일 이상 없으면 반복 리마인더 대신 "흐름 정리"를 제안한다. 회고 저장 후에는 고민 마무리, 같은 고민으로 조정 상담, 상황이 바뀐 새 상담 시작 중 하나를 고르게 한다.
- Postconditions: 오늘 로그, 실천 회고, 연장된 기간, 또는 DROPPED/COMPLETED 상태가 저장되어 다음 상담에 반영된다. 사용자가 고민 마무리를 선택한 경우에만 연결 상담 세션이 `RESOLVED`가 된다.
- Implementation Status: 구현됨. DB 상태값은 `ACTIVE | COMPLETED | DROPPED`를 유지하고, 멈춤/마감 상태는 화면에서 파생 계산한다.
- What the user must understand: 실천을 며칠 쉬었다고 실패가 아니며, 기록은 평가가 아니라 다음 방법을 더 현실적으로 만들기 위한 재료다.
- What the system must explain: 왜 지금 다시 기록, 마감 회고, 연장, 방법 변경 중 하나를 권하는지 마지막 행동일과 권장 기간 기준으로 짧게 설명한다.
- Where to reduce choice fatigue: 홈과 실천 탭은 여러 실천을 같은 강도로 보여주지 않고, 지금 처리할 1개를 먼저 올린다.
- Defaults / recommendations to show: 정상 진행은 오늘 미기록 항목을 추천한다. 3일 이상 멈춤은 재기록을 기본 CTA로 둔다. 기간 완료는 마감 회고를 기본 CTA로 둔다. 오래 멈춘 기간 완료 항목은 흐름 정리를 기본 CTA로 둔다. 회고 후 긍정적 완료 흐름은 고민 마무리를 먼저 두고, 멈춤/조정 흐름은 다음 상담에서 조정하기를 먼저 둔다.

## UC-07. 구독과 유지

- 사용자: 체험 종료 또는 반복 상담 니즈가 있는 사용자
- 목표: 상담-실천-기록-후속 상담 루프를 계속 사용한다.
- 결과: 월 구독으로 전환하거나 구독을 유지한다.

## UC-08. 공유와 재유입

- 사용자: 리포트를 가족과 나누려는 사용자
- 목표: 리포트 공유를 통해 가족 합의와 신규 유입을 만든다.
- 결과: 공유 열람자가 로그인, 설문, 리포트 흐름으로 유입될 수 있다.
