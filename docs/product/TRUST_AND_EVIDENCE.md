# 신뢰와 근거 원칙

## 신뢰의 역할

기질아이는 아이와 양육자의 민감한 데이터를 다룬다. 신뢰는 마케팅 문구가 아니라 분석 근거, AI 역할, 한계, 개인정보, 결제/환불 안내가 일관되게 맞을 때 만들어진다.

## 사용자에게 설명해야 할 것

| 영역 | 설명 |
|------|------|
| 분석 근거 | 기질 이론과 설문 응답 구조를 참고한 양육 자료임 |
| 개인화 근거 | 어떤 응답과 기질 차원이 생활 해석으로 이어졌는지 |
| AI의 역할 | 진단자가 아니라 고민을 구조화하고 실천안을 제안하는 도구임 |
| 한계 | 의학적·심리학적 진단을 대체하지 않음 |
| 개인정보 | 아이 정보와 고민 원문은 이벤트 분석에 보내지 않음 |
| 결제 신뢰 | 해지, 환불, 구독 상태를 사용자가 이해할 언어로 표시함 |

## 허용 문구

- 기질 이론과 표준화된 설문 구조를 참고해 만든 양육 참고 자료입니다.
- 의학적·심리학적 진단을 대체하지 않습니다.
- 발달, 건강, 안전과 관련된 우려는 전문기관 상담을 권장합니다.

## 금지/주의 문구

- 실제 검토가 없으면 `전문가 검토 완료`라고 쓰지 않는다.
- `치료`, `진단`, `장애 판정`, `정상/비정상` 표현은 피한다.
- AI가 아이 상태를 확정적으로 판단하는 톤을 쓰지 않는다.

## 운영 원칙

- 전문가 검토를 도입하면 검토자 자격, 검토 일자, 검토 범위, 검토하지 않은 범위를 문서화한다.
- 리포트와 상담의 근거 표시는 짧게, 사용자가 바로 이해할 수 있는 생활 언어로 제공한다.
- 상세 정책은 `../product/policies/report.md`, `../product/policies/consultation.md`, `../product/policies/payment.md`, `../product/policies/analytics.md`를 따른다.
