# 기질아이 한 장 요약

마지막 갱신일: 2026-05-30 · 현재 버전: v1.0.8+34

## 한 줄 정의

**기질아이(GIJILAI)** 는 3~7세 자녀를 둔 양육자가 아이의 기질을 이해하고, 리포트와 AI 상담을 통해 **오늘의 실천**까지 이어가도록 돕는 **지속관리형 육아 코치**다.

## 컨셉

과학적 기질 분석(CBQ-VSF / ATQ-SV)과 AI 전문가의 통찰을 결합해, "검사 결과를 읽는 데서 끝나는 진단 서비스"가 아닌 **상담 → 실천 → 기록 → 다음 상담**의 루프로 양육 행동을 바꿔준다.

## 타겟 사용자

- 3~7세 자녀의 행동을 기질 관점에서 이해하고 싶은 양육자
- 검사 결과를 실제 대화와 실천으로 옮기고 싶은 양육자
- 상담·실천·기록을 아이별로 누적해 다음 상담에 반영하고 싶은 사용자

## 목표 (제품 약속)

1. 아이의 행동을 **점수보다 생활 장면과 언어로** 해석한다.
2. 상담은 정답 생성기가 아니라 **현재 고민을 구조화하고 다음 행동을 정하는 도구**다.
3. **실천 기록이 쌓일수록 다음 상담의 맥락**이 좋아진다.
4. 리포트/상담은 의학적·심리학적 진단이 아닌 **양육 참고 자료**다.

## 핵심 흐름

```
랜딩/로그인 → 아이 등록 → 설문 → 리포트 → AI 상담 → 실천 기록 → 회고/후속 상담 → 구독 유지
```

## 현재 기능

| 영역 | 제공 기능 |
|------|-----------|
| **온보딩** | 랜딩, 소셜 로그인(카카오/Apple/Google, iOS는 네이티브 SDK·Android는 Custom Tab), 다중 아이 등록, 양육 고민(최대 3개) 접수 |
| **설문** | 아이 기질(CBQ-VSF, 36문항), 양육자 기질(ATQ-SV), 양육 태도. `빠른 아이 리포트` 분기 + 임시 저장 |
| **리포트** | 아이 기질 / 양육자 분석 / 기질 맞춤 양육 3개 탭, 레이더 차트, 통합 성향 카드, 관계 온도계, 마법의 한마디 |
| **AI 상담** | 입력 품질 검증, 비슷한 고민 예시 칩, 문진→후속질문→마음 처방전, 속마음 통역·관계 해석·오늘의 한마디·실천 항목 산출 |
| **상담 세션** | 동시 활성 **최대 3개** 고민 스레드, 추가 상담 시 이전 맥락+실천 기록을 LLM에 자동 주입 |
| **실천/기록** | 동시 활성 **최대 5개** 실천 항목, 매일 체크+한줄 메모, 마지막 행동일 기반 재시작/마감 회고/실천 마무리 안내, 로컬 알림 리마인더 |
| **홈** | 아이 프로필·선택, 양육자 유형, 구독/체험 상태, "지금 상황 SOS", "오늘의 실천" 카드, 다음 추천 행동 1개 우선 노출 |
| **구독/결제** | 7일 리버스 트라이얼 + **월 구독(KR 12,000원 / Global $9.99)**, 앱 IAP(Apple/Google) / 웹 포트원 V2 분기, 해지는 스토어 안내 후 상태 재조회 |
| **공유/추천** | 카카오톡·OS 공유, 리포트 저장, 가족 공유, UUID 추천 링크, 앱 WebView에서는 네이티브 공유 시트 |
| **운영/분석** | Firebase Analytics + GA4 퍼널, Crashlytics(앱 시작/WebView/IAP), 결제/환불 이력, 상담 품질 지표 |

## 수익 모델

| 단계 | 가치 | 목적 |
|------|------|------|
| 무료 | 아이 기질 진단·리포트·공유 | 첫 신뢰 형성 |
| 7일 체험 | 프리미엄 전체 경험 | 상담–실천 루프 체감 |
| 월 구독 | AI 상담, 전체 실천 이력, 다음 상담 맥락 누적 | 반복 사용/유지 |

구독 메시지는 *"무제한 이용"* 보다 *"기록이 쌓일수록 다음 상담이 더 정확해진다"* 는 지속관리 약속을 우선 전달한다.

## 기술 스택 요약

- **웹**: Next.js (App Router) + Firebase Analytics + Supabase Auth
- **모바일**: Flutter 쉘(`gijilai_app/`) + WebView 브리지(`ShareBridge`, `nativeAuthProviders`, 로컬 알림), Crashlytics
- **결제**: Apple/Google IAP (서버 알림·RTDN 동기화) + 포트원 V2 (웹 정기결제)
- **AI**: 기질 점수 산출 → 부모-자녀 궁합 분석 → AI 큐레이션 → 맞춤 처방전 파이프라인
