# 기능 맵

마지막 갱신일: 2026-05-31

## 온보딩

- 랜딩, 로그인, 아이 등록, 접수 정보 입력
- 목적: 첫 리포트까지의 마찰을 줄이고 아이별 맥락을 만든다.

## 설문

- 아이 기질, 양육자 기질, 양육 태도 설문
- 목적: 리포트와 상담의 기본 데이터를 만든다.
- 핵심 분기: 빠른 아이 리포트(`child_only`)와 전체 분석

## 리포트

- 아이 기질, 양육자 분석, 기질 맞춤 양육 3개 탭
- 목적: 점수보다 생활 장면, 속마음, 대화 스크립트로 신뢰를 만든다.
- 전환: 전체 분석 이어하기, 상담 시작, 가격 페이지, 공유

## 홈

- 아이 프로필, 아이 선택, 양육자 유형, 구독/체험 상태, 지금 상황 SOS, 다음 추천 행동 카드
- 목적: 사용자가 앱을 열었을 때 지금 가장 중요한 행동 1개를 바로 이해하게 한다.
- 현재 원칙: 홈 콘텐츠는 스크롤 reveal 애니메이션 없이 즉시 보이며, 실천 항목을 일부만 미리 보여줄 때는 남은 개수를 `+N개 더`로 표시한다.

## 상담

- 고민 입력, 문진 질문, 후속 질문, 마음 처방전
- 목적: 현재 고민을 기질 기반으로 해석하고 오늘의 행동을 정한다.
- 산출물: 속마음 통역, 관계 해석, 오늘의 한마디, 실천 항목
- 다자녀 보조: 상담 인사에서 아이 이름을 강조해 현재 상담 맥락을 더 쉽게 구분한다.

## 실천/기록

- 오늘의 추천 실천, 실천 체크, 한줄 메모, 첫 기록부터 아이 반응 기반 내일 조정안, 마지막 행동일 기반 재시작/마감 회고/실천 마무리
- 목적: 상담 결과를 반복 행동으로 전환하고 다음 상담 맥락을 쌓는다.
- 다자녀 보조: 아이가 여러 명이면 실천 카드에 아이 이름 태그를 표시한다.
- 입력 부담 완화: 일반 메모와 실천 마무리 회고는 선택 입력으로 유지한다.

## 구독/결제

- 7일 리버스 트라이얼, 월 구독, 앱 IAP/웹 결제 분기
- 목적: 리포트 단발 판매가 아니라 지속관리 루프를 판매한다.

## 공유/추천

- 리포트 공유, 가족 열람, 추천 유입
- 목적: 신뢰 재확인과 신규 유입을 만든다.

## 양육자 자신을 위한 상담 (self-parent)

- 양육자 본인의 마음 상담. 입력 → 2질문 → 짧은 인정+나에게 해줄 한 마디+오늘 나를 위한 한 가지.
- 진입: 아이 상담 결과 CTA + 홈 "오늘의 나" 초대 카드 + 상담 입력 화면 "아이 마음/내 마음" 토글.
- 실천 루프: "마음에 담기"로 자기 돌봄을 저장하고, "내 마음 기록"(`/consult/self/records`)에서 다시 보며 "이번 주 어떠셨어요?" 한 번의 부드러운 후속으로 마무리. 홈 "오늘의 나" 카드. **데일리 체크 없음**(숙제화 방지).
- 캐치프라이즈: "더 좋은 사람이 되기 위해 고민하는 것만으로 당신은 이미 좋은 사람." (pricing·상담 결과·양육자 탭·self 결과·내 마음 기록에 노출)
- 임상 경계: 진단·트라우마 작업 X, 위기 키워드 시 전문기관 안내 우선. 공동양육자에게 비공개(RLS type='CHILD' 한정).
- 목적: 부모 자기 작업을 루프에 넣어 수치심 없는 양육 코칭으로 재방문·신뢰를 만든다. 정책: `policies/self-parent.md`. 기획: `SELF_PARENT_CONSULTATION_PLAN.html`.

## 공동양육자(co-parent) 모드

- 한 아이에 두 번째 양육자 1명 초대(비대칭 owner→co-parent), 리포트·상담·실천 맥락 공유
- 호칭: 엄마/아빠/보호자 폐쇄형 enum, 두 양육자가 각각 선택
- 목적: nodtry 모델의 관계형 리텐션을 이식해 한 명이 잊어도 옆에 있는 분이 끌어오게 만든다.
- 검증 단계(Phase 1): 자동 푸시 없이 카카오톡 등 외부 채널로 수동. 자세한 정책: `policies/co-parent.md`. 기획: `COPARENT_RELATIONAL_RETENTION.md`.
