## 유즈케이스

### UC-01. 가입 전에 대화 예시를 보고 빠른 검사로 이어가기
- Goal: 사용자가 서비스가 주는 대화 도움을 이해하고 첫 검사를 시작한다.
- Actor: 신규 웹 방문자 또는 로그인한 재방문자.
- Preconditions: 공개 랜딩 또는 예시 링크를 열 수 있다. 개인정보 입력은 필요 없다.
- Trigger: 랜딩의 예시 CTA 또는 공유된 예시 링크를 누른다.

Basic Flow:
1. 시스템이 선택된 생활 장면과 고정된 대화 예시를 보여준다.
2. 사용자가 예시를 읽고 필요하면 복사하거나 공유한다.
3. 사용자가 빠른 검사 CTA를 누른다.
4. 시스템은 필요 시 로그인한 뒤 `/intake`로 복귀시켜 아이 정보와 필수 동의를 받는다.
5. 사용자는 기존 응답을 이어가거나 첫 검사에 답하고 1차 리포트를 확인한다.

Alternate Flow:
- A. 잘못된 장면 값은 기본 `transition` 예시로 열린다.
- B. 복사·공유가 지원되지 않거나 취소되면 예시 화면에 머물며 검사 진입을 계속 사용할 수 있다.
- C. 인증 실패 시 로그인/오류 안내를 표시하며 완료했다고 처리하지 않는다.
- D. 외부·인증 순환 목적지는 홈으로 바꾼다.

Postconditions:
- 예시 확인만으로 고객 데이터나 AI 결과를 생성하지 않는다.
- 로그인 성공 시 원래 검사 목적지가 유지되고 기존 응답은 보존된다.

Implementation Status:
- 현재 구현 — 코드 `92f6a81`, 로컬 통합 검증 및 2026-09-17 웹 프로덕션 배포·공개 흐름 smoke 완료.

What the user must understand:
- 예시는 개인 맞춤 분석 결과가 아니다. 아이에 맞는 설명은 실제 검사와 기존 상담에서 이어진다.

What the system must explain:
- 어떤 생활 장면의 예시인지, 지금 건넬 한마디, 다음 검사 행동을 화면에서 설명한다.
- 복사·공유 성공/실패를 실제 결과에 맞게 안내한다.

Where to reduce choice fatigue:
- 기본 생활 장면 하나와 검사 CTA 하나를 중심에 둔다. 설치나 전체 분석을 첫 행동의 필수 단계로 만들지 않는다.

Defaults / recommendations to show:
- 기본 장면은 `transition`, 검사 기본 흐름은 `quick`. 저장된 응답은 계속 사용한다.
