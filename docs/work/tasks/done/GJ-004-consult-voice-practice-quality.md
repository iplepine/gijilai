# GJ-004 상담/실천/음성 입력 UX 정리

상태: done  
완료일: 2026-05-04

## 범위

- 실천 회고 후 다음 행동 버튼을 `이 고민 마무리하기`, `다음 상담에 반영하기`, `새 고민으로 상담하기`로 정리했다.
- 상담 상세의 이어가기 버튼은 `이어서 상담하기`로 바꿔 기존 세션 맥락을 이어받는 동작을 더 명확히 했다.
- 음성 입력 오류는 실제 `SpeechRecognition`/`getUserMedia` 오류 코드별로 권한, 장치, 네트워크, 서비스 제한, 언어 미지원, 음성 미감지를 분기한다.
- Flutter WebView permission request는 Android뿐 아니라 iOS microphone-only 요청도 처리한다.
- 상담 시작 화면의 키보드 하단 여백은 `visualViewport` 기반 `--keyboard-inset-bottom`으로 보정한다.
- 상담/설문 문항 전환에는 이전/다음 방향성 slide 애니메이션과 reduced-motion 대응을 추가했다.

## 상담 품질 변경

- 초기 문진 4번째 질문은 양육자가 바라는 변화 또는 "나아졌다고 느끼는 모습"을 묻는다.
- 처방 프롬프트는 부모 목표를 그대로 정답 처리하지 않고 발달 단계, 기질, 지금 바꿀 부분과 지켜볼 부분을 검토한다.
- 결과 해설 흐름은 `핵심 상황 → 아이 입장 → 부모 감정/이미 시도한 방법 인정 → 목표 검토 → 작은 실천`으로 맞춘다.
- 실천 기본안은 부모 목표를 가장 작은 부모 주도 행동으로 낮춘다.

개선 후: "식사 자리에서 TV가 멈추면 아이에게는 즐거운 흐름이 갑자기 끊기는 순간일 수 있어요. 부모님은 한자리에 앉아 밥을 먹는 모습을 바라지만, 바로 긴 식사 시간을 요구하기보다 첫 3분만 화면을 멈추고 숟가락 한 번 들기처럼 시작 장면을 작게 만드는 편이 맞을 수 있습니다."
