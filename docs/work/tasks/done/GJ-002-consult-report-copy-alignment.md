## 목표

상담/리포트 UI 문구와 신뢰 정책 문서가 충돌하지 않게 맞춘다.

## 범위

포함:

- 리포트 탭/섹션의 사용자 노출 문구 정리
- 신뢰 정책의 금지 표현과 제품 문서 용어 정합성 정리
- 관련 한국어/영어 i18n 문구 업데이트

제외:

- 리포트 점수 산정 로직 변경
- 상담 모델/프롬프트 구조 변경
- 결제 플로우 변경

## 결과

완료 내용:

- 사용자 노출 탭 `아이 진단`을 `아이 기질`로 바꿔 의료적 오해를 줄였다.
- `양육 스타일 진단`을 `양육 스타일 점검`으로 바꿨다.
- `빠른 진단` 계열 문서 표현을 `빠른 아이 리포트`로 맞췄다.
- 리포트 제품 스펙, 리포트 정책, 기능 맵, 성공 로드맵, 수익/전환 설계 문서를 같은 용어로 정리했다.

검증 결과:

- 금지 표현 점검: 사용자 노출 리포트/제품 문서에서 `아이 진단`, `양육 스타일 진단`, `빠른 진단` 잔여 표현 없음

남은 리스크:

- 면책 문구의 `의학적 진단을 대체하지 않습니다`는 금지 표현이 아니라 한계 고지 문구로 유지한다.
